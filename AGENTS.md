# Agents

wahwah-avatar: 3D avatars driven by [wahwah](https://github.com/pomodorozhong/wahwah) performances. The playground shows several models at once, each driven by the same rendered utterance. TypeScript + Vite + Three.js, managed with npm. The `wahwah` package comes from a release tarball. See `README.md` to run it and `docs/goals.md` for what this repository owns.

Checks before committing: `npm run typecheck`, `npm test`, `npm run build`.
